# 工具箱图标尺寸与拖拽预览

## 1. 背景

RPA 工具箱（`src/components/rpa-browser/ToolboxPanel.vue`）中的动作图标自「自定义动作图标」上线后统一由
`ActionIcon` 渲染（`(icon_series, icon_id)` → `action-icons/` 静态资源），但视觉尺寸仍是接入初期的
16px（`w-4 h-4`），行高也偏紧（列表行 `py-2`、基础操作树沿用 Element Plus 默认 26px 行高），
配上 FGO 状态图这类细节较多的位图后辨认度较低。

同时拖拽使用浏览器默认行为：`dataTransfer.setData` 只传 payload，**未调用 `setDragImage`**，
因此拖拽影像是「被拖元素整行截图」（含文字、标签，宽高不定、还会被拉长），
落到画布上很难确认拖的是哪个动作。

## 2. 需求

1. **图标放大**：工具箱内的动作图标由 `w-4 h-4`（16px）放大到 `w-6 h-6`（24px），
   私有/公开列表与基础操作树保持一致；图标资源缺失时的兜底类型图标（`resolveActionTypeIcon`）同步放大。
2. **条目变高**：私有/公开列表行内边距 `py-2` → `py-3`；基础操作树行高由默认 26px 显式提到 48px
   （`el-tree-v2` 的 `item-size`，虚拟滚动依赖固定行高）。
3. **拖拽预览显示「设置的图标」**：拖拽时用该动作当前设置的图标渲染一个方形缩略图作为拖拽影像
   （`dataTransfer.setDragImage`），替代浏览器默认的整行截图；图标缺失时用内置类型图标兜底，
   保证「拖的一定能看出是什么」。

### 2.1 追加（第二轮：图标再放大 + 高度/滚动条修复）

4. **图标再放大**：`w-6 h-6`（24px）→ `w-8 h-8`（32px），列表行与树行高同步提到 56px
   （`item-size = 56`；列表 `py-3` + 32px 图标自然得到 56px）。
5. **工具箱外框变高**：`.toolbox-dialog` 由 `max-height: 75vh` 改为**定高 + 收紧上下外边距**
   （`margin-top: 5vh` / `margin-bottom: 0` / `height: 88vh`），面板由 `h-[70vh]` 改为 `h-full` 填满弹窗 body。
   原实现里弹窗被 `max-height: 75vh` 限高、面板却按 `70vh` 计算，底部内容直接被
   `overflow: hidden` 裁掉——**内层滚动条滚到底也看不到最后一行**（滚动容器比可视区还高）。
6. **只保留一条滚动条**：树容器去掉 `overflow-auto`（改 `overflow-hidden`，滚动交给 `el-tree-v2` 自己的虚拟滚动）；
   虚拟树高度改用 `ResizeObserver` 的 `contentRect.height`（内容盒，已排除 `p-3` 的 24px padding）。
   原先读 `clientHeight`（padding 盒）导致树比可用内容区高 24px，既多出一条外层滚动条，
   又让虚拟列表以为可视区更高、末行只露出一半。

## 3. 约束与实现口径

- 视觉表现一律用 Tailwind 原子类，不新增 `<style>` / `:style`；
  拖拽预览元素在 JS 中临时创建，其 class 同样使用主题语义类（`bg-bg` / `text-text-primary`）与
  Tailwind 内置类（`rounded-lg` / `shadow-lg`），class 字面量写在 `.vue` 源码中以保证被 Tailwind 扫描到。
- `setDragImage` 要求元素在调用瞬间位于文档中（允许移出视口），因此实现为：
  临时挂到 `body` → 调用 `setDragImage` → 下一帧卸载并移除。
- 图标尺寸/行高集中为模块级常量，避免模板与脚本两处各写一遍魔数。
- 预览图锚点取中心点，拖拽时图标中心跟随光标。

## 4. 非目标

- 不改画布（`ActionCard` / 画布节点）中的图标尺寸——画布侧尺寸由 `ActionCard` 自行决定，本次不动。
- 不改图标资源本身与「系列/编号」映射（见 `docs/rpa-自定义动作图标计划书.md` §5.5）。
- 不改拖拽 payload 结构（仍为携带 `icon_series` / `icon_id` 的 JSON）。

## 5. 验收

1. 私有/公开列表与基础操作树中的图标明显变大，行与行之间不再拥挤。
2. 基础操作树滚动到最后一项时，最后一行完整可见（`item-size` 与内容高度一致，虚拟滚动无裁切）；
   工具箱整体**只有树内部一条滚动条**，弹窗外侧不出现滚动条，底部条目不被弹窗裁切。
3. 从两个 tab 任意一条拖拽时，跟随光标的是一个**方形图标缩略图**，且与该项当前图标一致。
4. 未设置图标（`icon_series/icon_id = 0`）或资源缺失的动作，拖拽预览显示其内置类型图标，不出现空白方块。
5. 拖拽释放后页面上不残留临时预览元素。
