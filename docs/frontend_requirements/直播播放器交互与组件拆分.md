# 直播播放器交互与组件拆分（前端需求）

> 组件：`src/components/rpa-browser/LiveBox.vue` 及其子组件。
> 适用范围：归属者直播页（`BrowserStream`）与监管只读页（`AdminBrowserMonitorView`）。

## 1. 启动入口：播放器中央播放按钮

### 背景

原工具栏有独立的「启动直播 / 停止直播」按钮，与播放器自带的播放 / 暂停按钮**语义重复**：

- 用户会先找播放器按钮，找不到才去工具栏，动线割裂；
- 两处入口各自维护状态，容易出现「点了启动但界面显示未开播」。

### 现行约定

| 场景 | 入口 | 行为 |
| --- | --- | --- |
| 未开播 | 画面**中央大播放按钮**（`LiveCenterPlayButton`） | 弹「启动直播确认」（提示流量消耗）→ 建流 |
| 直播中 | 控制条左侧**暂停 / 继续**按钮（观看者级） | 暂停 / 恢复本端出帧，不重建连接 |
| 暂停中 | 画面**中央大播放按钮** | 恢复本端出帧（等同控制条的继续） |
| 直播中 | 控制条右侧**停止直播**按钮 | 关闭本观看者这一路（不影响其他观看者） |
| 会话挂起（`lifecycle=idle`） | 覆盖层「恢复直播」按钮 | 重建流，后端 `touch` 自动解除挂起 |
| 会话待关闭（`lifecycle=terminating`） | 覆盖层「续命」按钮 | 同上，并取消宽限期倒计时 |

**工具栏只保留标签页能力**（页签切换 / 新建页面 / 关闭页面），不再放直播开关。

## 2. 组件拆分

`LiveBox.vue` 曾接近 1800 行，现只做编排（组合 composable、分发状态与事件）。

### 组件（`src/components/rpa-browser/live/`）

| 组件 | 职责 |
| --- | --- |
| `LivePageTabs.vue` | 标签页工具条（页签 / 新建 / 关闭），只上抛事件 |
| `LivePlayer.vue` | 画面容器：`<video>` + 顶栏 + 控制条 + 覆盖层 + 中央播放按钮 |
| `LivePlayerTopbar.vue` | 顶部浮层：LIVE / 观看人数弹层 / 暂停·降档徽标 / 速率 |
| `LivePlayerControlBar.vue` | 底部控制条：暂停 / 人数 / 清晰度 / 停止 / 全屏 |
| `LiveCenterPlayButton.vue` | 中央大播放按钮（未开播 → 启动，暂停中 → 继续） |
| `LiveOverlay.vue` | 状态覆盖层（挂起 / 待关闭 / 连接中 / 已停止 / 未开播），互斥 |
| `LiveViewersPanel.vue` | 「谁在看」观看者列表（数据来自 SSE，不发请求） |

### Composable（`src/composables/`）

| Composable | 职责 |
| --- | --- |
| `useWebRtcConnection.ts` | 一条 PeerConnection 的生死：offer / answer / ICE / 关闭 |
| `useLiveStream.ts` | 启动 / 停止 / 自动重连 / 网速看门狗 / 清晰度 / 暂停 / 可见性 |
| `useLivePages.ts` | 标签页（会话级：新建 / 关闭 / 切换，切页后重建本端流） |
| `useLiveSessionStatus.ts` | 消费会话状态 SSE：人数 / 列表 / 生命周期 / 倒计时 |
| `usePlayerControls.ts` | 控制层自动隐藏（鼠标静止淡出）与全屏状态同步 |

### 模型（`src/models/rpa_browser/live_stream.ts`）

`LiveWebrtcStatus` / `LiveViewerInfo` / `LivePageTab` / `LiveQualityOption` /
`LiveOverlayState` / `LiveSessionState` —— 组件之间只传这些模型。

## 3. 约束

- 状态单一来源：`isStreaming` 由页面 `provide`、LiveBox `inject`，**只由 `useLiveStream` 写入**，
  父组件不得再做反转（历史上「emit 让父组件 toggle」会把刚启动的状态翻回未开播）。
- 子组件一律 props 进 / emits 出，不直接调接口；接口调用集中在 composable。
- 样式只用 Tailwind 语义化类，禁止 `<style>` 与内联样式；元素保留 BEM 功能类名。
