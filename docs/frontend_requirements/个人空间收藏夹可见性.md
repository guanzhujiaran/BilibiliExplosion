# 个人空间「收藏」去掉全局开关 + 收藏夹逐夹可见性

> 状态：需求已定稿（2026-10-08），后端 + 前端同步实施
> 关联：`docs/frontend_requirements/个人空间主页行为记录与隐私.md`、`docs/be-message-统一计划书.md` §5.25

## 1. 背景与结论

B 站用「合集 / 系列」承载 UP 主的内容聚合；本项目没有该功能，**由「收藏」承担同样职责**。
既然如此，「收藏」就不该由一个全局开关整体关闭，而应**每个收藏夹各自可选公开 / 隐藏**。

| 项 | 现状 | 本期 |
| --- | --- | --- |
| 设置页「在主页展示『收藏』」开关 | 全局开关（`TUserFavoriteSetting.showFavorites`） | **整项去掉**（设置页不再有收藏开关） |
| 收藏夹可见性 | 无字段，全部随全局开关一起公开 / 隐藏 | 新增 `TFavoriteFolder.is_public`，**逐夹独立**，默认公开 |
| 收藏 tab（他人视角） | 全局关闭 → 整个 tab 隐藏 | **恒展示**，只列**公开**的收藏夹（无公开夹时列表空态） |
| 收藏 tab（本人视角） | 恒可管理全部夹 | 不变：本人看到全部夹（含隐藏），可逐个切换公开 / 隐藏 |
| 时间线「收藏了什么」条目 | 受全局开关控制 | 只包含**公开夹**里的收藏；本人看到全部 |

设计口径：

- **默认值**：新建收藏夹**默认公开**；存量收藏夹迁移时**回填为公开**（保持原来的可见行为，
  不让历史数据突然全部不可见）。
- **本人 / 他人分流仍在前端**（`isOwnSpace`）：本人走 `/favorite/folder/list`（全量 + 可改），
  他人走 `/favorite/user/folders`（只含公开夹）。后端公开接口**不引入 viewer 参数**，
  只按 `is_public` 过滤 —— 避免为「同一个人既可能是主人也可能是访客」再造一套鉴权。
- 不提供「仅粉丝可见」等中间态（用户只要求公开 / 隐藏）。
- **收藏 tab 恒展示**（2026-10-08 二次调整）：不再因「他人无公开夹」隐藏 tab（避免额外判断 / 请求）；
  他人空间无公开夹时列表空态。**默认收藏夹同样可设公开 / 隐藏**（默认公开，但不可删除）。
- **收藏入口展示收藏夹属性**：收藏弹窗（`MomentFavoriteDialog`）逐项展示 名称 / 「默认」标记 /
  **公开 · 隐藏** / 描述 / 封面。

## 2. 接口变更（影响 HTTP 契约 → 需重新生成 hey-api SDK）

| 接口 | 变更 |
| --- | --- |
| `POST /favorite/folder/create` | 请求体新增 `isPublic: bool = true` |
| `POST /favorite/folder/update` | 请求体新增 `isPublic: bool \| None`（缺省 = 不改） |
| `GET /favorite/folder/list`（本人） | 响应 `FavoriteFolderResp` 新增 `isPublic` |
| `GET /favorite/user/folders`（他人） | **去掉全局开关门控**，只返回 `isPublic=1` 的夹；无公开夹时返回空数组（不再 403） |
| `GET /favorite/user/dynamics`（他人） | 只返回**公开夹**内的收藏；无公开夹时返回空数组（不再 403） |
| `GET/POST /favorite/setting` | **删除**（`FavoriteSettingReq` / `FavoriteSettingResp` 一并删除） |
| `GET /user/space/info`、`GET /user/space/privacy` | `privacy_flags` 去掉 `show_favorites` 字段 |
| `POST /user/space/privacy` | 不变（本来就不含收藏） |

## 3. 后端实现

1. **模型**：`TFavoriteFolder` 新增 `is_public: bool`（列名 `is_public`，`NOT NULL DEFAULT 1`）；
   删除 `TUserFavoriteSetting` 表（全局开关已无意义）。
2. **迁移**：一条 alembic 版本同时做 `ADD COLUMN is_public`（回填 1）与 `DROP TABLE TUserFavoriteSetting`。
3. **服务** `FavoriteFolderAction`：
   - `create` / `update` 接收并写入 `is_public`；
   - `list_folders` 返回项带 `isPublic`；
   - `list_public_folders`：去掉全局 `is_public` 门控，改为 `WHERE mid = :mid AND is_public = 1`；
   - `list_public_items`：只取公开夹内的收藏（JOIN `TFavoriteFolder.is_public = 1`）；
   - 删除全局的 `get_setting` / `set_setting` / `is_public`。
4. **路由** `api/favorite.py`：删除 `/setting` 两个路由；`/user/folders`、`/user/dynamics`
   不再返回 403，改为返回过滤后的结果。
5. **空间属性**：删除 `FavoritesAttribute`、`AttributeKey.FAVORITES`、
   `AttributeStorage.FAVORITE_SETTING`（`SPACE_ATTRIBUTES` 5 → 4）；
   `SpacePrivacyFlags.show_favorites` 删除；`SpacePrivacyService.get_flags` 只读隐私表。
6. **时间线** `space_timeline.py`：收藏条目的门槛由「全局开关」改为「本人 OR 该条收藏所属夹公开」，
   即本人看全部、他人只看公开夹内的收藏。
7. **注销清理** `cleanup_favorite.py`：去掉 `TUserFavoriteSetting` 的删除。

## 4. 前端实现

1. `SpaceSettingsTab.vue`：删除「主页展示」卡片与开关，以及 `showFavorites` / `setShowFavorites` 的引用。
2. `SpaceFavoritesTab.vue`：收藏夹列表项与编辑弹窗新增「公开 / 隐藏」开关（`el-switch`），
   保存时提交 `isPublic`；本人视角恒可切换。
3. `MomentSpaceView.vue`：`showFavorites` 语义改为「他人视角下是否存在可展示的公开夹」（本人恒 `true`）；
   删除 `setShowFavorites`；`refreshFavorites` 按新语义计算。
4. `spaceContext.ts`：删除 `setShowFavorites`，保留 `showFavorites` / `refreshFavorites`。
5. `moment-api.ts`：删除 `fetchFavoriteSetting` / `setFavoriteSetting`；
   `createFavoriteFolder` / `updateFavoriteFolder` 请求体带上 `isPublic`。
