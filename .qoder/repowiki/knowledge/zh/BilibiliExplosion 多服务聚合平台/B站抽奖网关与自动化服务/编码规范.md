- HTTP 响应统一封装为 `base_api_model` 实例，包含 code/data/msg/ttl 四字段，业务错误通过 code 区分而不改变 HTTP 状态码。
- Controller 层使用 express-validator 对请求体/查询参数进行校验，校验失败通过 `next(errors.mapped())` 交由全局错误中间件统一处理。
- 权限控制通过 `createGuard()` 守卫装饰路由处理器，结合 `JwtModule` 的 jwtAuth 中间件完成认证与授权。
- 数据访问层 DAO 方法对外暴露静态方法，用户相关读写已迁移为通过 `callRpc` 调用 be-message 服务，不再直连本地数据库。
- 服务类采用静态方法组织（如 UserService、UserDao），通过 class 命名空间聚合同一领域的异步方法。
- 配置文件集中加载：`config/index.js` 从 `config.yml` 解析 YAML 配置，运行时参数通过 `config/run_arg.js` 解析命令行 --port/--env。
