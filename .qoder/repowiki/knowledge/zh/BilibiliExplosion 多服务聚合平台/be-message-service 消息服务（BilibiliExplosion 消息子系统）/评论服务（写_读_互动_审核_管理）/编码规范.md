- 写路径对计数类字段一律使用 `UPDATE ... SET col = col + delta` 的数据库侧原子自增，禁止读到内存后 +1 再写回，以避免并发丢更新。
- 所有对外可见的评论过滤统一通过模块级常量 `VISIBLE_STATES = (CommentStateEnum.NORMAL,)` 进行，写/读/互动/管理各分支保持一致。
- 评论树形结构仅支持两层（一级评论 + 楼中楼），深层回复通过 `reply_to_mid` 展示为「回复 @xxx」而非真实嵌套，由 `_resolve_tree` 统一校验并推导 root/parent/dialog/reply_to_mid。
- 列表与详情组装强制走 `assemble_items` 单一入口，正文、用户快照、互动态均通过 `WHERE rpid IN (...)` 批量回捞，禁止循环内逐条查询。
- 通知与事件投递（回复/@/点赞/审核结果）作为弱依赖，捕获异常仅记录日志不污染主事务，且通过独立会话或 `new_session()` 隔离。
- 评论正文中的 @提及统一以 `@{mid}` 占位符存储，发布时经 `normalize_at_mentions` 将前端传入的昵称映射替换为 mid 占位符，读取时再还原为昵称。
