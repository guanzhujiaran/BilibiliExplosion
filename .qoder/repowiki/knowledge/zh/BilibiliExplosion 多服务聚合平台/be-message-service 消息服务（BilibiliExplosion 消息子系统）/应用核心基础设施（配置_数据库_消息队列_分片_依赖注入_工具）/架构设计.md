本模块按职责划分为三个并列子包，构成服务启动后其他业务层依赖的基础设施：
- `app/core`：核心运行时能力。`config.py` 基于 pydantic-settings 的 `Settings` 集中声明所有环境变量（RabbitMQ、MySQL/PPTR Postgres、Alembic、EdgeRank、JWT、Casdoor、推送渠道等），并通过 `model_post_init` 做证书换行转换与连接池上限防御；`database.py` 用 SQLAlchemy 创建 MySQL 主引擎与 pptr Postgres 引擎，分别暴露 `get_session`/`get_pptr_session` FastAPI 依赖和 `new_*_session` 非请求上下文构造器，并提供 `ensure_database`/`test_connection` 启动自检；`broker.py` 通过 lazy import 复用 `app.mq.router.broker`，集中声明 TOPIC exchange `message_exchange` 与各 routing_key/queue 常量，供消费者与 HTTP 发布方共享避免绑定不一致；`sharding.py` 实现「msgkey 毫秒时间戳→月度库名 + msgkey%100→表名」的分片路由，配合进程内 `_ensured_shards/_ensured_dbs` 缓存与 `asyncio.Lock` 懒创建当月 100 张分表；`migration.py` 封装双 Alembic 分支（主库 MySQL 与 pptr Postgres）的 `upgrade head` 调用。
- `app/dependencies`：FastAPI `Depends` 集中存放。`user.py` 从 `x-bili-*` 请求头解析 `AuthInfo`，并在网关降级时回退到 JWT 验签；`admin.py` 在 root 之外再查 `msg_admin` 表赋予细粒度权限；两者通过 `__init__.py` 统一 re-export 给各 API 路由使用。
- `app/utils`：无状态纯函数工具集。`ip_mask.py` 负责客户端 IP 提取与 IPv4/IPv6 打码；`route_target.py` 收敛前端跳转目标为 `route:{name}?query` 并校验注册路由；`notify_markup.py` 生成 B 站风格 `#{text}{"url"}` 内联链接并做安全白名单过滤；`audit_source.py` 把 `(oid, type)` 翻译为审核后台的内容来源与跳转；`ua_parse.py` 轻量解析 UA 得到 plat/device。
依赖方向单向向下：业务层 → dependencies → core/config+database；utils 不反向依赖 core。
