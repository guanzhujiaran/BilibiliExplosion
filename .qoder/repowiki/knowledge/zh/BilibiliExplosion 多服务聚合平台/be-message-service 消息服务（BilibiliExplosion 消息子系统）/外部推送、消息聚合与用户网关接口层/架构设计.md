本模块由四个独立的 FastAPI `APIRouter` 组成，分别挂载到 `/api/v1/message/push`、`/api/v1/message/msg_feed`、`/api/v1/user`、`/api/v1/message/admin`，统一通过 `StandardResponse` 返回。
- `external_push.py`：将上游微服务（RPA-Browser / nodejs-pptr）的推送请求经 RabbitMQ broker 发布到 `message.push` 队列，或调用 `PushMessageService` 直接发送测试/反馈推送；认证依赖 `CurrentUser`，不做 JWT 校验，信任网关注入的 `x-bili-*` 头。
- `msg_feed.py`：聚合入口，一次请求汇总事件（BaseEvent）、通知（NotifyService）、私信（DmInbox）未读数并计算 total，同时提供活跃心跳上报给 ActivityService。
- `pptr_user_gateway.py`：承载从 pptr 迁移过来的全部用户接口，包括导航信息、个人资料 CRUD、黑名单、注销账号（异步 MQ 投递）、角色设置、用户搜索、空间信息、JWT 续期（HttpOnly Cookie `bili_jwt`）、Casdoor OAuth 回调等；鉴权使用 `CurrentUser`/`RootUser`/`AdminUser` 依赖，数据库访问区分主库 SessionDep 与 pptr Postgres 的 `new_pptr_session`。
- `message_admin.py`：独立的消息管理端权限授权路由，仅 root 可 grant/revoke/list，任意登录用户可查自身状态，数据落 `msg_admin` 表并由 `MessageAdminService` 封装。
依赖方向单向向下：router → service → core/database + core/broker + bili_common.models，不反向引用上层应用。
