- 所有路由统一以 `APIRouter(prefix=..., tags=[...])` 声明，并以 `StandardResponse[Model]` 作为 response_model 包装返回值。
- 鉴权通过 FastAPI 依赖注入 `CurrentUser`/`RootUser`/`AdminUser`，路由函数内不再自行解析 `x-bili-mid` 或校验 JWT。
- 需要写操作的接口捕获异常后统一返回 `StandardResponse(code=..., msg=...)`，而非抛出 HTTPException（部分业务如 push/test 采用此模式）。
- 跨服务调用失败（MQ 发布、Casdoor token 刷新等）采用 best-effort 策略：记录 warning 日志但不阻断主流程。
- 分页查询统一使用 `offset + limit` 参数并通过自定义 `parse_*_query_params` 依赖函数解析，避免 SQLModel 直接作 Depends 导致 OpenAPI schema 生成问题。
- 对 pptr Postgres 的访问显式使用 `new_pptr_session()` 上下文管理器，与主 MySQL 的 `SessionDep` 严格区分，防止跨库 session 混用。
