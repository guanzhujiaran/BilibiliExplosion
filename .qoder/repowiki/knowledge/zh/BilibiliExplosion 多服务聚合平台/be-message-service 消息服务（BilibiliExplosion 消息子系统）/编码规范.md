- HTTP 路由统一返回 StandardResponse 包装体，参数校验由 Pydantic Schema 承担并委派至对应 Service。
- 业务实体采用 SQLModel 表模型与 Pydantic Schema 一一对应，分别位于 `models/db` 与 `models/schemas`。
- 跨进程交互通过 `app.mq.rpc_*` 声明 RPC 接口并由 FastStream Consumer 实现，避免直接 HTTP 调用。
- 异步任务与后台处理统一通过 RabbitMQ 队列消费，而非线程池或定时轮询。
- 多数据库访问通过 `core.database` 提供的异步会话工厂区分主库与 pptr Postgres。
