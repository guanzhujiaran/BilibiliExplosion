- 每个路由函数返回 `StandardResponse[...]`，业务异常通过捕获 `ValueError` 并以 `StandardResponse(code=400/422, msg=str(e))` 返回，保持路由层无 try/except 分支的简洁结构。
- 需要鉴权的写接口使用 `RequiredUser` 或 `RootUser` 依赖注入获取当前用户 mid，读接口（Feed/详情）则从 `x-bili-mid` Header 解析可选的 viewer_mid。
- 互动类接口（点赞/点踩/分享/举报/审核）统一通过 `get_biz(InteractionBizTypeEnum.DYNAMIC, session, biz_id, user.mid)` 获取资源实例后调用对应方法，避免在路由中重复拼装 bizId/dynId。
- 分页参数统一使用 `page_num`/`page_size` 并通过 `Query(..., ge=1, le=50)` 限制范围，列表接口默认 20 条。
- 客户端 IP 与 UA 通过 `_client_ctx(request, user_agent)` 提取后作为 `client_ip`/`user_agent` 传入服务层，用于审核日志记录。
- 外部弱依赖（如 RPA RPC、抽奖 RPC）采用失败降级策略：RPC 异常时返回空结果或放行，保证主链路不被下游不可用影响。
