本模块由四个 FastAPI `APIRouter` 组成，按业务域拆分到独立文件：
- `moment.py`：用户端 `/api/v1/community` 路由，覆盖发布（create/edit/remove/repost/top）、互动（thumb/dislike/share/report/status）、话题广场/@/POI 等；通过 `get_biz(InteractionBizTypeEnum.DYNAMIC, ...)` 复用 `interaction_actions.BaseBiz` 资源类实现幂等互动。
- `moment_feed.py`：Feed/详情路由 `/api/v1/dynamic`，支持综合流、关注流、个人空间、批量详情、点赞明细与转发列表，仅关注流强制登录（`RequiredUser`），其余接口以可选 `x-bili-mid` 解析 viewer_mid。
- `moment_audit.py`：管理员审核路由 `/api/v1/community/audit`，全部受 `RootUser` 守卫，调用 `MomentAuditService` 完成待审列表、统计、历史流水、approve/reject。
- `moment_topic_audit.py`：话题创建审核路由 `/api/v1/community/topic/audit`，同样 root 守卫，调用 `MomentTopicAuditService`。

依赖方向单向向下：路由层 → `app.services.moment.*` / `app.services.interaction_actions` / `app.services.user.follow` / `app.services.infrastructure.rpa_rpc`，不直接操作 ORM；数据库会话通过 `SessionDep` 注入，鉴权通过 `RequiredUser`/`RootUser` 依赖注入。所有写接口以 `ValueError` 抛业务异常，由统一中间件转为 `StandardResponse(code=400/422)`，路由层只负责参数校验与状态码映射。浏览计数通过 `publish_interaction_view` 投递 MQ 异步累计，避免阻塞主链路。
