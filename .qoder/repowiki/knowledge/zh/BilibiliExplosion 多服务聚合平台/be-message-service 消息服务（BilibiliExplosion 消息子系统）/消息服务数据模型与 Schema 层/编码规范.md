- 数据库表模型统一继承 `TimestampMixin`，使用 `default_factory=datetime.now` 与 `sa_column_kwargs={'onupdate': datetime.now}` 维护创建/更新时间。
- 枚举一律继承 `IntEnumAutoDoc`，并通过 `sqlalchemy.Enum(...)` 映射到 MySQL 原生 ENUM 列，落库存成员名而非整数值。
- HTTP/MQ 响应模型继承 `AutoStrMixin`，对 64 位 ID 字段同时提供 `xxx`（int）与 `xxxStr`（str）双字段以规避浏览器 Number.MAX_SAFE_INTEGER 精度问题。
- 请求体中可接收前端传入字符串 ID 的字段统一使用 `StrInt` 类型，在服务端内部转为 int 处理。
- ORM 表通过 `__table_args__` 显式声明主键、外键、唯一约束与索引，并在 `comment` 中说明用途。
- 跨服务共享的交互/举报/通知枚举直接从 `bili_common.models` 导入复用，不在本模块内重新定义。
