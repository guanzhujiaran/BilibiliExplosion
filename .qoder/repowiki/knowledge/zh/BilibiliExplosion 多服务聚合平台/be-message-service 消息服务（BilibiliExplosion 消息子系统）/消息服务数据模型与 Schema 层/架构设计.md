模块按三层划分：
- `app/models/db/`：基于 SQLModel 的数据库表模型（`table=True`），继承 `base_tbl.py` 中的 `TimestampMixin`（统一 created_at/updated_at）和 `ResourceBase`（通用 bizType/bizId/mid 骨架），每个业务实体一个文件（如 `moment_tbl.py`、`dm_tbl.py`、`notify_tbl.py`），通过 Alembic 管理 DDL。
- `app/models/schemas/`：HTTP 请求/响应与 MQ 载体，全部继承 `schemas.base` 再导出的 `AutoStrMixin`，实现 64 位雪花 ID 同时输出 int 与 str 双字段以避免前端精度丢失；`mq.py` 集中定义 RabbitMQ 消息体（DmContentPayload、EventPushPayload、NotifyPushPayload 等），与 HTTP 解耦。
- `app/models/enums.py`：集中所有 `IntEnumAutoDoc` 枚举（MessageModuleEnum、DmMsgTypeEnum、MomentAuditStatusEnum 等），复用 `bili_common` 的交互/举报/通知枚举，避免重复定义。
顶层 `__init__.py` 作为统一出口，重新导出常用枚举与历史 push/user 模型以保持向后兼容；`push.py`、`user.py`、`casdoor.py`、`pptr_user.py`、`str_int.py` 为独立领域模型（推送请求体、用户信息、Casdoor 集成、PPTR 用户回查、StrInt 类型）。依赖方向单向：db → enums，schemas → enums，无反向引用。
