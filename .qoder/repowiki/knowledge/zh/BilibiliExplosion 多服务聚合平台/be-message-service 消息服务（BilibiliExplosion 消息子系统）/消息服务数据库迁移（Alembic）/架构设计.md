模块包含两个并列的 Alembic 配置目录，分别对应不同数据库与职责：
- `alembic/`：管理主 MySQL 元数据库（`settings.mysql_message_url`），通过 `create_async_engine` + `connection.run_sync` 在异步环境中执行迁移；`target_metadata` 指向全局 `SQLModel.metadata`，并启用 `compare_type=True`、`compare_server_default=True` 以生成精确 diff；离线模式使用 `mysql_sync_url`。
- `alembic_pptr/`：管理 pptr 的 Postgres 库 `PTR_Bili_Lot`，将 asyncpg URL 替换为 psycopg2 同步驱动；通过 `include_object` 回调仅纳入 `app.models.pptr_db.__all__` 中声明的表，避免把 MySQL 表误同步进 Postgres。
- 迁移脚本位于各自 `versions/` 下，由 alembic autogenerate 生成 `upgrade()`/`downgrade()` 对；pptr 基线迁移 `init_pptr_production_baseline.py` 为空操作，仅锁定生产库当前结构，后续演进再增量生成。
- 依赖方向单向：env → app.core.config.settings / app.models.*，不反向被业务代码引用。
