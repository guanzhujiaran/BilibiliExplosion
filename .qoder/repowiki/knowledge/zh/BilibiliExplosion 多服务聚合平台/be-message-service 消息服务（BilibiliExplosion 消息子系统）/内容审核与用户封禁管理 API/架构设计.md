三个独立的 FastAPI `APIRouter` 模块，分别挂载到不同 URL 前缀：`/api/v1/user/avatar/audit`（头像审核）、`/api/v1/favorite/folder/cover/audit`（收藏夹封面审核）、`/api/v1/message/admin`（封禁管理）。每个路由文件仅负责参数解析、鉴权守卫与响应包装，业务逻辑委托给 `app.services.user.*` 下的 Service 层（如 `AvatarAuditService`、`FolderCoverAuditService`、`UserGovernanceUser`），数据库会话通过 `SessionDep` 注入。鉴权采用分层策略：普通用户查询使用 `CurrentUser`，管理员操作使用 `RootUser`；封禁模块进一步基于 `bili_common.models.depends.AuthInfo` 与 `require_permission(UserPermission.*)` 实现按服务维度（comment/dm）的细粒度权限校验，并通过 `_SERVICE_BAN_PERM` 映射表集中维护服务到权限枚举的对应关系。所有响应统一封装为 `StandardResponse`，异常通过捕获 `ValueError` 转为 404 错误码。
