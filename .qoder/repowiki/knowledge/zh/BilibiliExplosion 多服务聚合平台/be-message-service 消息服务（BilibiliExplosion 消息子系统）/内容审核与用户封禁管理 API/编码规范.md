- 每个路由文件独立定义一个 `APIRouter` 并导出 `router`，通过 `__all__ = ["router"]` 暴露给上层聚合。
- Handler 函数仅做参数校验与调用 Service，数据库会话通过 `SessionDep` 注入，不直接访问数据库。
- 管理员接口统一使用 `RootUser` 依赖守卫，普通用户接口使用 `CurrentUser`，并在注释中明确标注角色要求。
- 请求体与响应体类型来自 `app.models.schemas.*` 中的 Pydantic/SQLModel 模型，响应统一用 `StandardResponse[...]` 包裹。
- 分页参数统一使用 `page_num`、`page_size` 并以 `Query(default=..., ge=..., le=...)` 声明约束。
- 封禁类写操作的权限校验集中在 `_check_ban_permissions` 中，通过 `_SERVICE_BAN_PERM` 映射表逐项检查所需权限，缺失时返回 403 并指明缺少哪个服务权限。
