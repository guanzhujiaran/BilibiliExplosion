- 每个路由函数统一使用 `@router.<method>(path, response_model=StandardResponse[...], summary=...)` 声明，并以 `StandardResponse(data=...)` 或 `StandardResponse(code=..., msg=...)` 作为唯一返回值。
- ID 类参数（rpid/oid/msgkey/talker_mid 等）在路由层统一做字符串→整数的 try/except 转换，非法值直接返回 `code=400` 的 `StandardResponse`，不向下游抛出。
- 写操作前调用对应 `*AdminUser(mid=user.mid).is_banned(session, BanServiceEnum.XXX.value)` 进行封禁拦截，被封禁时返回 403 并附带中文提示。
- 管理端路由通过 `RootUser` 限制写操作（审核/批量审核），读操作使用 `MsgAdminUser` 并按 `user.is_root` 分支决定可见状态集合与非 root 字段脱敏。
- 可选登录态接口通过 `Depends(resolve_optional_viewer)` 从 `x-bili-mid` 头解析 viewer mid，缺失时视为匿名并触发降级策略（如匿名用户 page_size 限 10）。
- 审核操作采用统一的 `_OP_TO_STATE = {"pass": NORMAL, "reject": REJECTED, "hidden": HIDDEN, "restore": NORMAL}` 映射表，将字符串 op 转换为枚举状态后再调用 Service。
