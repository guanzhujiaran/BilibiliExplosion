- 每个文件定义一个 `APIRouter` 并通过 `__all__ = ["router"]` 暴露，由上层聚合挂载到应用。
- 写操作统一用 try/except 捕获 `ValueError`，将其转换为 `StandardResponse(code=400/422, msg=str(e))` 的业务错误响应。
- 需要登录的接口通过 FastAPI `Depends(CurrentUser)` 或 `Depends(RequiredUser)` 注入当前用户，避免手写鉴权逻辑。
- 雪花 ID 类字段（mid、folderId、bizId）统一通过 `StrInt` 配合 `Annotated[..., Query(...)]` 接收，以兼容前端传字符串。
- 分页参数使用 `Query(default=..., ge=..., le=...)` 声明式校验，并在路由函数内直接透传给 Service 层。
- 响应体一律封装为 `StandardResponse[data]`，成功时 `code=0`，失败时复用同一结构返回错误码与消息。
