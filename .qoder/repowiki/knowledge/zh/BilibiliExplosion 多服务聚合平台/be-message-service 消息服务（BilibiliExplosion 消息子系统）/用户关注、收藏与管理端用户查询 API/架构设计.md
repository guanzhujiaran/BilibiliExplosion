模块由三个独立的 FastAPI `APIRouter` 组成，分别挂载到不同前缀：`user.py` 挂载 `/api/v1/message/admin/user`（仅管理员 root 可调用），`follow.py` 挂载 `/api/v1/message/follow`，`favorite.py` 挂载 `/api/v1/favorite`。
- 依赖方向：路由层仅做参数解析与异常包装，业务逻辑下沉至 `app.services.user.follow.FollowService`（关注/拉黑）、`app.services.interaction_actions.folder.FavoriteFolderAction`（收藏夹 CRUD）以及通过 `get_biz(InteractionBizTypeEnum, ...)` 动态分派到各资源类型的交互动作；用户主数据通过 `app.services.user.account.PptrUser` 直读 pptr Postgres 只读副本。
- 鉴权分层：关注接口使用 `CurrentUser` 依赖，收藏接口使用 `RequiredUser`，管理端用户搜索额外校验 `is_root`。
- 统一响应：所有接口返回 `StandardResponse`，错误通过捕获 `ValueError` 并转为 `code=400/422` 的业务错误码，而非抛出 HTTPException。
- 数据模型：请求/响应 schema 集中在 `app.models.schemas`（如 `FollowReq`、`FavoriteAddReq` 等），中间类型 `StrInt` 用于兼容前端以字符串传递雪花 ID。
