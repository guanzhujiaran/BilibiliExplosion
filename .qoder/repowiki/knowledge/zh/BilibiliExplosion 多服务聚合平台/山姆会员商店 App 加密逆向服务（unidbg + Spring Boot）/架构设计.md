模块采用典型的三层结构：Controller 层 `doEncrypt` 暴露 `/api/app/samsclub` REST 接口；Service 层通过单例工厂 `Encryptor`（静态内部类懒加载）集中管理 unidbg 资源，并派发到具体业务实现 `SamClubEncrypt`；Model 层使用 Lombok 注解的 DTO 承载请求体。运行时由 `UnidbgSpringBootApplication` 启动 Spring 容器，`Encryptor` 构造时通过 `ResourceUtils.getFile("classpath:...")` 从 resources 下加载 `apk/samsclub/cn.samsclub.app_5.0.120.apk` 与 `so/samsclub/libsrmscy.so`，并用 `AndroidEmulatorBuilder.for32Bit()` 创建 32 位 Android 模拟器、设置 `AndroidResolver(23)`、加载 Dalvik VM 与 SO 库，再调用 `SecurityTools.update/doEncrypt` JNI 静态方法完成加密。`SamClubEncrypt` 继承 `AbstractJni`，通过重写 `getStaticObjectField` 和 `callStaticObjectMethodV` 拦截 Native 对 Java 静态字段/方法的访问，注入密钥、包名与证书串等桩数据，从而绕过真实设备依赖。依赖方向单向：Controller → Service → unidbg 模拟器，不反向依赖框架。
