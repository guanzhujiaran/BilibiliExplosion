- Controller 使用 `@RestController` + `@RequestMapping` 按业务域划分路径，并以 `@Tag` 标注 OpenAPI 分组。
- Service 层通过私有构造器配合静态内部类 `SingletonHolder` 实现线程安全的懒加载单例，统一封装 unidbg 初始化与异常包装。
- JNI 交互通过继承 `AbstractJni` 并重写 `getStaticObjectField` / `callStaticObjectMethodV`，以签名字符串 switch 分支方式返回桩值或转发调用。
- APK 与 SO 文件以 classpath 资源形式存放于 `resources/{apk,so}/...`，通过 `ResourceUtils.getFile("classpath:...")` 读取而非硬编码绝对路径。
- DTO 使用 Lombok `@Getter` 生成访问器，保持 Controller/Service 间仅通过纯数据对象传递参数。
