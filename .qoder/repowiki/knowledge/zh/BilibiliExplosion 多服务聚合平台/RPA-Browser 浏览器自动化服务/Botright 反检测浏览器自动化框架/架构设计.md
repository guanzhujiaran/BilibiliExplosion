模块以 `botright.py` 中的 `Botright`（继承自 `async_class.AsyncObject`）为顶层入口，负责启动 Playwright/undetected-playwright、选择 Chromium 内核、组装启动参数并创建 `BrowserContext`。
- `playwright_mock/`：对 `playwright.async_api` 的 `BrowserContext/Page/Locator/Mouse/Keyboard/Frame/Handles/Routes` 进行子类化与装饰，通过保存 `_origin_*` 引用并在 `new_page`、`route`、`expose_function`、`expect_console_message` 等方法中注入自定义行为（如缓存响应、拦截图片、包装 Route/Request），从而在不修改上游 API 的前提下扩展功能。
- `modules/`：横向能力组件，`ProxyManager` 解析代理字符串并通过多个 IP 地理 API 推断国家/时区/经纬度；`Faker` 使用 `browserforge.fingerprints` 生成一致的 UA、屏幕尺寸、语言区域，并与 `ProxyManager.country_code` 联动；`geetest`/`hcaptcha` 提供验证码识别；`proxy_manager` 与 `faker` 在 `Botright.new_browser` 中被构造后注入到 `BrowserContext`。
- `extended_typing.py` 暴露 `NotSupportedError`，用于在启用 `use_undetected_playwright` 时抛出 CDP 补丁导致的不支持方法异常。
依赖方向单向：`Botright` → `playwright_mock.browser` → `playwright_mock.*`，各 mock 子模块仅反向引用 `modules` 与 `extended_typing`，不反向依赖 `Botright`。
