模块采用 FastAPI 按领域拆分路由器的扁平结构：`controller/v1/admin/` 下每个 `*_router.py` 对应一个管理子域（admin、permission、report、approval、tag、certification、audit、user_ban、admin_role），统一通过 `base.py` 的 `new_admin_router` / `new_notify_router` 借助 `gen_api_router` 包装并挂载到全局路由；`__init__.py` 聚合各子路由器为单一 `router` 供上层挂载。数据模型集中在 `models/system/`，使用 SQLModel 定义请求/响应 DTO（如 `rpa_admin.py`、`permission.py`、`admin.py`、`user_ban.py`），与数据库表模型分离。业务逻辑下沉至 `app/services/RPA_browser/*_service.py`，控制器仅做参数校验与响应封装。审计能力由独立服务 `services/admin_audit.py` 的 `log_admin_action` 提供，以 try/except 隔离写入失败，确保不影响主流程。所有接口统一返回 `bili_common.models.response.StandardResponse`，并通过 `RouterTag.admin_management` 打标签。
