- 每个管理子域独立一个 `*_router.py`，内部创建 `APIRouter(tags=[RouterTag.admin_management])` 并暴露模块级 `router` 变量，由 `__init__.py` 统一 include。
- 控制器函数统一使用 `try/except` 包裹业务调用，成功走 `success_response(data=...)`，异常走 `error_response(msg=..., code=ResponseCode.INTERNAL_ERROR)`。
- 请求与响应模型均基于 SQLModel 的 `Field(description=...)` 定义，并在文件末尾通过 `__all__` 显式导出。
- 管理员操作成功后通过 `services.admin_audit.log_admin_action` 异步记录审计日志，且审计写入失败仅告警不中断主流程。
- 对运行时配置（如浏览器会话清理策略）的修改直接写回 `app.config.settings`，并以注释明确说明仅内存生效、重启恢复。
