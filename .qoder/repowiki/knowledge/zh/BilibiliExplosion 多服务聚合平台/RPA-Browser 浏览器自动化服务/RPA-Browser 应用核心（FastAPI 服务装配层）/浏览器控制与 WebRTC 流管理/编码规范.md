- 每个业务域在 `controller/v1/browser_control/<domain>/router.py` 中定义路由，并通过 `base.py` 的 `new_<domain>_router()` 工厂统一包装后注册到 `all_routes`。
- 所有 HTTP 端点统一返回 `bili_common.models.response.StandardResponse`，成功走 `success_response(data=...)`，失败走 `error_response(code=ResponseCode.XXX, msg=...)`。
- 会话访问前通过 `Depends(verify_browser_ownership)` 校验浏览器归属，并结合 `AuthInfo` 从请求头解析用户身份。
- `LiveService` 中以 `mid_{browser_id}` 拼接字符串作为会话键，并使用 `asyncio.Lock` + 全局 `_global_lock` 保护 `_browser_sessions` 字典的读写。
- WebRTC 流通过 `WebRTCStreamManager` 的双向索引（`_streams_by_index` 与 `_streams_by_key`）进行 O(1) 查找，新增/访问时通过 `_touch_lru` 更新 OrderedDict 顺序以实现 LRU 淘汰。
- 异步资源释放统一使用 `contextlib.suppress(Exception)` 包裹关闭操作，避免单个资源异常影响整体清理流程。
