- 每个业务实体以 `XxxCrudService` 类组织，所有方法声明为 `@staticmethod`/`@classmethod`，并通过 `async with DatabaseSessionManager.async_session() as session:` 包裹数据库操作。
- 列表查询统一支持 `skip`/`limit` 分页与 `sort_by`/`sort_order` 动态排序，排序字段通过 `getattr(Model, sort_by, default)` 安全获取后配合 `col(...).asc()/desc()` 排序。
- 可见性过滤采用一致的 `filter_type` 分支（private/public/community/verified/all），组合 `mid == str(mid)` 与 `is_public`/`is_verified` 条件构建查询。
- 名称唯一性校验在 create/update 中通过查询同用户同名记录，命中则抛出 `NameAlreadyExistsException(name=..., name_type=...)`。
- Fork/Duplicate 操作生成新 ID（uuid4 或 `ca_`+hex），复制原记录核心字段，设置 `forked_from_id`，并将原资源 `forks_count` 原子递增/递减。
- API 请求/响应模型集中在 `models/workflow/models.py`，使用 Pydantic `Field(description=...)` 标注字段语义，并通过 `__all__` 显式导出。
