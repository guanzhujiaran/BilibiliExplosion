本模块按职责划分为三个子目录，构成上层业务服务的底层支撑：
- `app/models/database/*`：基于 SQLModel 的持久层模型，按业务域拆分子包（admin、browser、log、notify、workflow），每个子包内定义表模型并导出 `__all__`；通过 `alembic_migration.py` 在启动时统一 import 所有模型以注册到 `SQLModel.metadata`，再执行 Alembic `upgrade head` 与 schema 一致性校验（区分 critical 与 non-critical 差异）。
- `app/models/runtime/*`：面向浏览器运行时的 Pydantic/SQLModel 请求响应模型与内部 dataclass，包括 `api.py`（指纹 CRUD、打开 URL、截图、释放等操作）、`session.py`（会话生命周期参数/响应）、`live_service.py`（`BrowserSessionEntry` 会话条目，封装过期/闲置/清理策略）、`control.py`、`webrtc_models.py`、`simplified.py`、`operations.py`，被上层服务用于序列化浏览器控制指令。
- `app/utils/*`：横切工具与依赖注入，核心包括 `depends/session_manager.py` 中的 `DatabaseSessionManager`（全局 `AsyncEngine` + 连接池配置 pool_size=20/max_overflow=30/pool_pre_ping=True/pool_recycle=300，带 DisconnectionError/OperationalError 重试与自动回滚）、`depends/admin_depends.py`（`require_root`/`require_admin`/`require_permission`/`assert_approved` 等 FastAPI 依赖）、`http/httpx_client.py`（`AsyncHttpClient` 单例 + 全局 client 及 get/post/put/delete 快捷函数）、`middlewares/ban_guard.py`（Starlette 中间件拦截被封禁用户）、`controller/router_path.py`（根据 `RouterPrefix.ADMIN` 决定是否拼接 `controller_base_path` 生成路由前缀）、`snow_flake_gen.py`（全局雪花 ID 生成器）、`bigint_utils.py`、`alembic_migration.py`、`utils/consts/browser_exe_info/` 等。
依赖方向：runtime 模型依赖 database 模型与 core 公共模型；utils 被 runtime 与上层 service/controller 共同引用；database 不反向依赖 utils，仅依赖 `BaseSQLModel` 与外部 `bili_common`。
