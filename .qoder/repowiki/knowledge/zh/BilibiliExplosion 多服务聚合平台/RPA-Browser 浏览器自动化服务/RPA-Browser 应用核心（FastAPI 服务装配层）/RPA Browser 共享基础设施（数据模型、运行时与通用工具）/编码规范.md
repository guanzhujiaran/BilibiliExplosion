- 数据库模型统一继承 `BaseSQLModel`，使用 `Field(..., description=...)` 标注字段语义，并通过文件末尾 `__all__` 显式导出模型类。
- 运行时 API 请求/响应模型采用命名约定：`*Params` 表示请求体、`*Resp` 表示响应体，均基于 `SQLModel`/`Pydantic` 定义并在 `__all__` 中集中导出。
- 数据库访问统一通过 `DatabaseSessionManager.get_db_session()` 或 `async_session()` 获取 `AsyncSession`，并在异常分支中对 `DisconnectionError`/`OperationalError` 进行重试与回滚处理。
- 权限校验以 FastAPI 依赖形式暴露（`require_root`、`require_admin`、`require_permission`），从请求头解析身份后查库验证 `rpa_admin` 表，越权抛出 `PermissionDeniedException`。
- 对外部资源（HTTP 客户端、数据库引擎、雪花 ID 生成器）采用模块级单例/全局变量管理，通过工厂函数（如 `get_global_http_client`）提供访问入口。
- 路由前缀生成依据 `RouterPrefix.ADMIN` 特殊处理：Admin 路由直接使用自身 prefix，其他路由拼接 `settings.controller_base_path` 后再挂载。
