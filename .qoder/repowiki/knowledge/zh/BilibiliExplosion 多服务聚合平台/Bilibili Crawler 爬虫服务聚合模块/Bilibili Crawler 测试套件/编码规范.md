- 通过 `conftest.py` 中的 `app` fixture 构建最小 FastAPI 实例并 include 各 router，测试文件内再创建 `client` fixture 复用该 app 发起请求。
- 对外部依赖（service、redis、broker、LLM 等）一律使用 `unittest.mock` 或 `monkeypatch.setattr` 进行替换，避免真实网络/数据库调用。
- 数据库相关测试使用 SQLite 内存引擎 + 自定义 SqlHelper 子类覆盖 MySQL 特有语法（如 TINYINT、on update CURRENT_TIMESTAMP），并在 fixture 中 DDL 建表。
- MQ 测试将发布与消费解耦：先 mock redis_obj 与 broker，再用 FastStream TestRabbitBroker 做内存端到端验证，集成用例通过 `RUN_MQ_INTEGRATION` 环境变量条件跳过。
- 测试数据以 fixtures/*.json 形式存放 Bilibili API 响应样例，供解析类测试直接加载断言。
- 参数化测试统一使用 `@pytest.mark.parametrize` 驱动多组用例，并通过 `ids=lambda c: c.name` 生成可读的测试 ID。
