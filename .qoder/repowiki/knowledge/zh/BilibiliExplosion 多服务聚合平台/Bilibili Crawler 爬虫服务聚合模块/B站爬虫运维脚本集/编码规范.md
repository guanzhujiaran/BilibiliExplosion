- 每个可执行脚本以 `if __name__ == '__main__':` 或 `__main__.py` 作为入口，内部封装 `main()` 函数并通过 `asyncio.run(main())` 启动事件循环。
- CLI 参数统一通过 `argparse.ArgumentParser` 定义，并使用 `_cli_utils.add_llm_args` / `add_db_args` 注入 LLM 与数据库参数组，再由 `apply_cli_overrides` 覆盖全局 `CONFIG.settings`。
- 批量处理采用“分片 + 并发 worker”模式：先按 `batch_size` 切分批次，再用 `_run_workers_concurrent` 配合 `asyncio.Semaphore(concurrency)` 并发执行，每个 worker 捕获异常返回 `'grand'/'not_grand'/'error'` 并汇总统计。
- 数据库写入采用“逐条立即保存”策略（每处理完一条记录就调用 `save_extra_info`），避免批量提交中途失败导致结果丢失。
- 脚本通过 `build_mysql_uri(db_name, args)` 构造 `mysql+aiomysql://` URI 并 new 出独立的 SqlHelper 实例，再替换各 Service 模块的全局单例，从而让已导入模块的连接池生效于新数据库。
- LLM 客户端优先从 `settings.llm_apis` 中取第一个可用配置创建 `ChatOpenAI`，当传入 `--llm-headers` JSON 时额外注入 `default_headers` 以支持鉴权/路由头。
