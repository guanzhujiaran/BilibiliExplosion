本模块为扁平的脚本目录，按功能域划分子包：
- `judge_grand_prize/`：通过 `__main__.py` 暴露 CLI 入口，基于 argparse 解析参数后调用 `judge_common_lottery` / `judge_reserve_lottery` / `judge_official_lottery` 三个异步函数，分别对普通抽奖动态、预约抽奖、官方/充电抽奖执行 LLM 大奖判断并写入 `t_lot_extra_info`；使用 `_run_workers_concurrent` + `asyncio.Semaphore` 控制并发，`tqdm` 输出进度。
- `_cli_utils.py`：提供 `add_llm_args` / `add_db_args` / `apply_cli_overrides` / `build_mysql_uri` 四个通用工具，被 judge 脚本复用，负责把 `--llm-*` 和 `--db-*` 参数注入到项目级 `CONFIG.settings`，并通过构造新的 `SqlHelper` 实例覆盖各 Service 模块的全局单例连接池。
- `database/`：按数据源划分的回填与同步脚本（如 `backfill_dyninfo_from_rawjson`、`bili_lottery_statistic_database`、`同步向量数据库`），每个子目录是一个可独立运行的脚本。
- `bili/`：直接调用底层 `Service.*` 模块完成具体业务动作（如获取丢失抽奖通知、手机端首页刷视频、打卡、专栏一键发布、私信/点赞列表抓取）。
- `代理/`、`光猫ip/`：辅助运维脚本（添加代理、光猫 IP 配置示例）。
依赖方向单向向下：脚本 → `Service.*` / `CONFIG` / `Utils`，不反向被业务代码引用；LLM 客户端统一经 `langchain_openai.ChatOpenAI` 构建，数据库访问经 `mysql+aiomysql` URI 直连。
