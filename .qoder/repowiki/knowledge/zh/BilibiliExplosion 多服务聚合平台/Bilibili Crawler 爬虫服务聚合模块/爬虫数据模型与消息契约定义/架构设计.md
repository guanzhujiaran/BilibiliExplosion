模块以 `Models/base/custom_pydantic.py` 中的 `CustomBaseModel` / `CustomGenericModel` / `CustomBaseModelHashable` 为统一基类，提供 `extra='allow'` 扩展字段、`extra_fields` computed_field 以及将超大整数序列化为字符串的 `dict()` 行为，所有业务模型均继承该基类以获得一致的序列化与哈希能力。

按职责划分为若干子目录：
- `MQ/`：基于 `faststream.rabbit` 的 RabbitMQ 消息契约，`BaseMQModel.py` 通过 `QueueName`/`ExchangeName`/`RoutingKey` 三个 `StrEnumAutoDoc` 枚举集中管理队列名、交换机和路由键，并由 `MQPropBase` dataclass 封装 `RabbitQueue` 实例与发布路由键拼接逻辑；`MQRouterModels.py` 汇总所有可入队的参数类型形成 `MQ_PARAMS_JOINED_TYPE` 联合类型，作为 MQ 路由分发器的类型约束。
- `lottery_database/bili/`：B站抽奖核心领域模型，`LotteryDataModels.py` 包含 `LotdataResp`、`ReserveInfoResp`、`OfficialLotteryResp`、`ChargeLotteryResp`、`CommonLotteryResp`、`AllLotteryResp` 等响应模型及 `BiliBusinessTypeEnum`、`BiliLotStatisticLotTypeEnum` 等业务枚举，并通过 `pydantic_model_to_filter_params` 工具函数从模型注解自动推导前端筛选元数据；同目录下 `milvusModel/`、`redisModel/` 分别存放向量库与 Redis 存取模型。
- `v1/`：按业务域划分的 API 模型，包括 `CaptchaGen`、`ChatGpt3_5`、`GeetestDet`、`background_service`、`bili`、`ip_info`、`samsclub` 等子包，每个子包内仅放置对应领域的请求/响应模型。
- `AntiRisk/Bili/WebCookie.py`：封装 B站 Web Cookie 生成与序列化，`BiliWebCookie` 通过 `model_post_init` 从 `GenWebCookieParams` 派生 `buvid_fp`、`uuid`、`browser_resolution`，并提供按顺序拼接 cookie 字符串的 `to_str` 方法；`CookieWrapper` 用于包装 Cookie 及其 UA、过期时间与重试计数。
- `BaseCrawler/model.py`：提供 `NoneParams` 等基础占位模型。

依赖方向单向向下：业务模型 → `base.custom_pydantic`；MQ 模型 → `BaseMQModel`；数据库模型不反向依赖 MQ 或业务模型，保持契约层纯粹。
