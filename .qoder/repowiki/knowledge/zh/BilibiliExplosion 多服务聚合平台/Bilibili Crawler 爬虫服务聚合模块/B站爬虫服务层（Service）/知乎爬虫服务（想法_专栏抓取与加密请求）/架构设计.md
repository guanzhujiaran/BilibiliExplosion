模块分为两层：
- `zhihu_src/` 为底层 HTTP 客户端层，`ZhihuMethod` 通过 `httpx` 发起请求，使用 `enc/zhuhu_enc.py` 中的 `execjs` 调用 `zhihu_encrypt.js` 生成 `x-zse-96` 签名并维护 `d_c0` cookie，再配合代理模块 `Utils.代理` 完成鉴权后的 API 调用（`get_moments_pin_by_user_id`、`get_pin_comment`、`get_pin_detail_by_pin_id`）。
- `获取知乎抽奖想法/根据用户空间获取想法/GetMomentsByUser.py` 为业务编排层，`LotScrapy` 基于 `Service.PlayWright.Operator` 的 Playwright 实例监听 `/api/v4/v2/pins/*/moments?*` 响应，分页拉取指定用户的 pins，解析为 `PinDetail`（区分 `moment`/`zhuanlan` 两种类型），按内容是否含抽奖关键词分流到 `lot_pin_details` 与 `non_lot_pin_details`，并通过 `records/` 目录下的 JSON/TXT 文件做增量去重与断点续爬。
依赖方向单向：业务层 → 加密层 → 网络/代理；数据落盘统一由 `end_write` 写入 `zhuhu_result/` 下的 CSV 日志。
