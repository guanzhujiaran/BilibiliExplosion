模块采用分层架构：
- `main.py` 定义两个基于 `Service.BaseCrawler.UnlimitedCrawler` 的爬虫类 `SamsClubCrawler`（按一级/二级分类批量拉取SPU列表）和 `SamsClubSPUDetailCrawler`（拉取已上架SPU的详情），通过 `key_params_gen` 生成任务、`handle_fetch` 执行抓取，并以单例 `sams_club_crawler` / `sams_club_SPU_detail_crawler` 暴露。
- `api/samsclub_api.py` 中的 `SamsClubApi` 封装所有HTTP调用，统一经 `send()` 方法发起请求，内置重试、加密密钥(siv/ssk)动态更新、token失效自动刷新、灰度配置(`gray_config_strategyDetails`)维护以及 `init_api_info` 中模拟App启动时的一整套初始化请求序列。
- `tools/` 提供签名与反混淆能力：`headers_gen.SamsClubHeadersGen` 生成带 `st` 签名的请求头；`do_samsclub_encryptor`、`java_rand_gen`、`samsclub_string_decryptor` 处理服务端下发的加密参数。
- `Sql/` 层基于 SQLAlchemy 异步会话，`models.py` 定义 SpuInfo、GroupingInfo、CrawlTaskProgress 等ORM模型，`SqlHelper` 提供 bulk_upsert、任务进度跟踪、未完成任务恢复等能力，并通过 `gen_model.py` 从数据库反向生成模型。
- `exceptions/error.py` 集中定义 `StopError`、`UnknownError`、`AUTH_FAIL` 等异常类型，被 API 层在响应码分支中抛出以驱动上层重试或告警。
依赖方向：main → api → tools + exceptions；main → Sql；api 不依赖 main，仅依赖工具与异常。
