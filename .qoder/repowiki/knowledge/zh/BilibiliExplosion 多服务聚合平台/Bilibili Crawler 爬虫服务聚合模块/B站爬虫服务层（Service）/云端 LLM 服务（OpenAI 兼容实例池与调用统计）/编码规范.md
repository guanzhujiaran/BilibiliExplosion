- 对外 API 统一通过 `__init__.py` 重导出，内部模块不直接暴露，保证与旧版 `Service/llm_service.py` 的导入兼容。
- LLM 实例的生命周期由模块级缓存管理：配置哈希变化才重建，避免重复建连并保留跨调用的统计累积。
- 对共享可变状态（如 `_robin_idx`、`_LLM_GLOBAL_LOCK`）采用单例式全局变量，并在注释中说明其在 asyncio 单线程事件循环下的原子性假设。
- 统计信息通过 Pydantic `BaseModel` 的 `computed_field` 派生衍生指标（available、rate_per_minute、avg_latency_seconds、avg_tokens_per_call），序列化时自动包含。
- 采样参数以 `StrEnumAutoDoc` 枚举 + 字典映射的方式集中管理，调用方通过 `to_kwargs(**overrides)` 生成并可覆盖默认值。
