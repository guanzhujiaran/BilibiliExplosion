- 每个爬虫子模块遵循 fetcher → parser → filter → model → sql_helper 的分层结构，职责单一且可独立测试。
- 对外部网络请求统一封装在 GrpcModule/Bapi 或各自 api/tools 中，业务逻辑不直接拼接 URL 或构造请求头。
- 数据持久化统一通过 SQLAlchemy 模型（gen_model.py/models.py）+ SqlHelper 访问 MySQL，避免裸 SQL。
- 爬虫间通过 MQ 层的 BasicAsyncClient/BasicMQ 进行解耦通信，禁止跨模块直接 import 业务函数。
- 需要 LLM 能力的模块统一从 llm_service 获取实例池，而非自行创建 ChatOpenAI 对象。
- 定时任务统一在 BackgroundService 中注册，并由 APScheduler 管理生命周期，不在业务模块内自启调度器。
