模块按职责划分为四层：
- API 层 (`src/FastApiReturns/SpaceFeedLotService/ToutiaoSpaceFeedLot.py`)：`ToutiaoSpaceFeedLotService` 作为对外入口，基于文件时间戳控制定时触发，调用爬虫主流程并读取结果文件返回抽奖 ID 列表。
- 爬虫核心 (`src/spider/SpaceFeed/SpaceFeedScrapy.py`)：`ToutiaoSpaceFeedSpider` 单例类，使用 `asyncio.create_task` 并发抓取多个用户空间，通过 `max_behot_time` 分页拉取，依据 `last_spider_user_id_recorder.json` 去重并检测上一轮已获取 ID 终止；最终将非视频/文章/微头条且含 `origin_thread` 的内容筛选为抽奖数据写入 CSV。
- 网络与加密 (`src/Tools/ApiTools/API.py` + `src/Tools/Enc/ToutiaoDecrypt.py`)：`ToutiaoAPI` 基于 `httpx.AsyncClient` 发起请求，通过 `execjs` 执行 `Toutiao_a_bogus.js` 计算 `a_bogus` 参数，并使用自定义 `@retry()` 装饰器实现重试；响应经 `APIRespTool.FeedListApi` 解析为结构化对象。
- 数据持久化 (`src/db/models.py` + `src/db/SqlHelper.py`)：SQLAlchemy ORM 定义 `TFEEDDATA`（id/publish_time/zippedData），`SqlHelperSpaceFeedDataDb` 继承 `dao.base.sqlHelperBase`，使用 `sqlite+aiosqlite` 异步连接，所有写操作加 `@retry_on_error()` 重试。
- 配置与状态：`src/ToutiaoSetting.py` 集中数据库 URI，`spiderSetting.json` 维护目标 `user_id_list` 与最大间隔时间，运行时状态通过 `FileMap` 指向 `AllIdList.txt`、`AllLotIdList.txt`、`last_spider_user_id_recorder.json`、`result/latest.csv`、`log/all.csv` 等文件进行跨进程/重启持久化。
依赖方向单向：FastApiReturns → spider → Tools → db，爬虫不反向依赖上层服务。
