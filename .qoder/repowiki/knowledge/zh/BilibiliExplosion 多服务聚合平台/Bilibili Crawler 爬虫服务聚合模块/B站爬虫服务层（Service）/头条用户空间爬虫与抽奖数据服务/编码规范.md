- 异步 I/O 统一通过 `@retry()` / `@retry_on_error()` 装饰器包装，对网络请求和数据库操作提供自动重试与延迟等待。
- 外部可配置项集中放在 JSON 或 Python 配置类中（`spiderSetting.json`、`ToutiaoSetting.CONFIG`），爬虫启动时再读入内存覆盖默认值。
- 运行时中间状态与去重集合以文本文件形式持久化（`AllIdList.txt`、`AllLotIdList.txt`、`last_spider_user_id_recorder.json`），并通过 `FileMap` 类统一管理相对路径。
- 爬虫主类采用自定义 `@Singleton` 装饰器保证全局唯一实例，避免重复初始化 HTTP 客户端与数据库连接。
- 数据模型使用 dataclass 描述（`LastIdResult`、`ScrapedDataContainer`、`LotDataInfo`），字段通过 `field(default_factory=...)` 提供可变默认值。
- 数据库访问封装为 `SqlHelperSpaceFeedDataDb` 子类，所有写方法使用 `async_session().begin()` 事务提交，读查询使用 `select(...).where(...)` 构造语句。
