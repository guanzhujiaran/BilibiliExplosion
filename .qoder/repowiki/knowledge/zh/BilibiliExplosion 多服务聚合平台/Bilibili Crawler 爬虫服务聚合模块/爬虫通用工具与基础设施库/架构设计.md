本模块按职责划分为多个子包，彼此通过 CONFIG 配置中心与日志模块解耦，不直接依赖业务 Service：
- `通用/`：提供异步重试装饰器（`retry_wrapper`、`sql_retry_wrapper`、`log_max_count_retry_wrapper`）、协程聚合 `asyncio_gather`、全局线程池与调度器、时间戳/动态 ID 转换等基础能力，被其他子包广泛复用。
- `数据库/SqlalchemyTool.py`：进程内缓存 `AsyncEngine` 与 `async_sessionmaker`，按 `(dburl, is_crawler)` 键复用连接池，避免多 helper 叠加打满 MySQL 连接数。
- `redisTool/RedisManager.py`：封装同步/异步 Redis 客户端，统一使用连接池 + `@retry` 装饰器处理连接断开与 BusyLoadingError，并提供 SCAN/MGET/ZSET/HASH 等批量操作。
- `代理/SealedRequests.py`：基于 curl_cffi 的 `requests.AsyncSession` 实现带浏览器指纹伪装（impersonate）和随机 TLS Cipher 的异步 HTTP 客户端，并支持 socks/http 代理注入。
- `加密/wbi加密.py`：实现 B站 WBI 签名流程，通过 `My_dm_img_Redis` 缓存 img_key/sub_key 并每日刷新，配合 `gen_dm_args` 生成弹幕参数。
- `GrpcUtils/`：提供 gRPC 响应解压与 protobuf 反序列化工具，以及极验点击验证码、UserAgent 解析、metadata 生成等辅助。
- `FastAPI/FastapiLifespan.py`：定义 FastAPI lifespan 钩子，启动时校验 MySQL/Redis/RabbitMQ/Milvus 等依赖连通性、执行 alembic upgrade head、确保 Milvus 集合存在并拉起后台任务；`alembic_manager.py` 负责迁移脚本执行。
- `设计模式/designMode/singleton.py`：提供基于 `asyncio.Lock` 的异步单例装饰器。
- `推送/`、`网关/gateway_auth.py`、`机器学习/抽奖信息分类/LotteryClassifier.py`：分别封装第三方通知推送、网关鉴权及预训练模型加载。
依赖方向：上层业务仅依赖本模块暴露的类/函数，本模块内部各子包之间通过相对导入协作，无循环依赖。
