模块以 `alembic/<业务库>/` 为单位组织，每个子目录都是一个独立的 Alembic 项目根：包含 `env.py`（迁移入口）、`script.py.mako`（版本脚本模板）和 `versions/`（按 revision ID 命名的迁移脚本）。每个 `env.py` 通过 `sys.path.insert(0, parent.parent)` 将父级 FastAPI 应用加入导入路径，从对应 `Service.*.models` 中导入 `Base.metadata` 作为目标元数据，并从全局 `CONFIG.database.MYSQL.<xxx>_URI` 读取该库的异步 MySQL URL，再交由 `sqlalchemy.ext.asyncio.create_async_engine` 创建连接；`run_migrations_online` 使用 `asyncio.run` 启动异步迁移，`run_migrations_offline` 走纯 SQL 文本模式。各库之间完全解耦，互不依赖，仅共享同一套 Alembic CLI 与 mako 模板。
