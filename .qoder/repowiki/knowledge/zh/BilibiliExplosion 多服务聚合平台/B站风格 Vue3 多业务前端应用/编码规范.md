- 路由统一在 `src/router/index.ts` 中以 `CustomRouteRecordRaw` 数组集中声明，并通过 `meta` 描述标题、图标、登录/管理员要求、排序与是否展示在首页。
- 业务 API 按领域拆分到 `src/api/<domain>/`，其中 browser、community、bili_lottery_data 等通过 hey-api 自动生成 TypeScript 客户端，其余手写 Axios 封装。
- 全局状态以 Pinia store 形式存放于 `src/stores/*.ts`，并按业务域命名（如 `rpa_admin.ts`、`message_admin.ts`、`moment.ts`）。
- 可复用 UI 组件放在 `src/components/<domain>/`，通用基础组件放在 `src/components/CommonCompo/`，页面视图放在 `src/views/<domain>/`。
- 跨组件状态与副作用通过 `src/composables/use*.ts` 暴露组合式函数，避免在组件内直接操作全局变量。
- 类型定义集中在 `src/models/` 下按业务域组织，组件与 store 通过引用这些类型保证前后端数据结构一致。
