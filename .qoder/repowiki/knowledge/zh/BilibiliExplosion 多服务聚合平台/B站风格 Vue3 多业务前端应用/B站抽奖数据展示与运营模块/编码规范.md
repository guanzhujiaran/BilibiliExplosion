- API 文件以 class 形式封装（如 `LotteryDataBaseApi`、`LotteryDataStatisticApi`、`DolotteryApi`），并在文件末尾实例化后默认导出单例供组件 import。
- 所有后端响应统一通过 hey-api 生成的 Service 调用，并以 `RootObject<T>` 包裹返回类型，再在方法内按需解包 `res.data` 或直接 `as any` 透传。
- 组件采用 `<script setup lang="ts">` 语法，props 通过 `defineProps` 声明并配合 `PropType` 进行类型约束，事件通过 `defineEmits` 显式定义。
- 列表页统一通过 `useLotteryData` 组合式函数管理分页、loading、error 与 extraFilters，再由 `BiliPaginationDataView` 渲染，避免在各页面重复实现分页逻辑。
- 筛选参数通过 `getLotteryFilterParams` 动态获取 `FilterParamMeta` 元数据，并由 `LotteryFilterBar` 根据 `param_type`、`enum_values`、`widget` 等字段动态渲染控件。
- 错误提示统一通过 `biliMessage.error` 弹出，成功/失败分支中均对 `resp.code` / `resp.is_succ` 做判断后再处理业务数据。
