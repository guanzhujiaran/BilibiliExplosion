模块按 Vue3 组件与 API 两层组织：
- 组件层 `components/lottery_data/`：以 `LotteryHome.vue` 为入口，`bili_data/` 子目录承载 B 站抽奖数据主界面（`OfficialLottery.vue`、`ChargeLottery.vue`、`ReserveLottery.vue`、`TopicLottery.vue`、`OthersLotDynList.vue` 等），通过 `useLotteryData` 组合式函数统一分页、筛选与加载；`BiliLotteryCard.vue` 是核心展示单元，封装奖品、倒计时、参与条件、互动（点赞/收藏/转发/评论）与原始数据折叠面板；`BiliAtariRanking.vue` + `BiliAtariResultSlot.vue` 实现中奖排行榜与用户详情抽屉；评论区由 `LotteryCommentSection.vue` / `LotteryCommentItem.vue` / `LotteryCommentMention.vue` 复用。
- API 层 `api/lottery_data/bili/`：`lottery_database_bili_api.ts` 基于 hey-api 生成的 `V1BiliService` 封装查询、提交、搜索、筛选元数据、爬虫状态等接口，并提供兼容旧接口的 `handle_lottery_data` 等方法；`lottery_data_statistic_api.ts` 封装抽奖统计/排行接口；`api/do_lottery/bili_do_lottery_api.ts` 直接调用 `/api/v1/do_lottery/bili/run|stop` 启动或停止账号抽奖任务。
依赖方向单向：组件 → `@/utils/useLotteryData.ts` / `@/stores/*` → `@/api/*` → hey-api 客户端 → 后端；组件之间通过 props/emits 与全局 store（如 `bili_lottery_record`、`global_var`）通信，不直接耦合 API。
