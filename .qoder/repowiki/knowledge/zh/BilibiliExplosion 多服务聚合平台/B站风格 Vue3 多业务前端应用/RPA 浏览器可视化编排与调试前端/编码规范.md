- 所有 HTTP 请求统一使用 businessHandler 包装，传入对应的 *Service 方法与 { successMessage, errorMessage } 选项，再根据 result.success 分支处理数据。
- 操作反馈以 item.id 为 key 写入 operationFeedback 记录表，并通过 setOperationFeedback / closeOperationFeedback 集中更新与清理，UI 侧按 id 读取对应反馈详情。
- 可复用执行逻辑封装为 Composition Function（如 useDebugboxExecution、useDebugboxItems、useDebugboxSave），通过回调函数注入父组件的数据访问方法，保持组件与业务逻辑解耦。
- 后端枚举在本地以 TS enum 定义并提供中文映射对象与 getter（如 SessionLifecycleState + SessionLifecycleStateLabel + getSessionLifecycleStateLabel）。
- 动作卡片通过 action_id 到图标/标题/描述映射表的键值查找来渲染，新增动作类型只需扩展映射表即可。
- 嵌套分支（if-else/loop）通过 DroppedItem.trueBranch/falseBranch/loopBody 递归结构表达，执行时借助 BranchPathStep 路径数组定位任意深度的子节点。
