- Feed 列表统一通过 `LoadingMoreContainer` 封装 loading/more/error 状态，并在 `onMounted` 触发首次加载。
- 动态 ID 全程以字符串传递（19 位雪花 ID 超出 JS Number 安全范围），在路由 params、API 参数、弹窗 bizId 等处均显式 `String()`。
- 互动统计（点赞/评论/转发/收藏/浏览）统一通过 `/interaction/status` 批量接口获取，再注入到 `MomentCard` 的 `status` prop，卡片自身不再发起统计请求。
- 内容渲染采用统一的 `MomentContentNode[]` 节点模型，由 `MomentContentRenderer` 按 type（WORDS/AT/TOPIC/LINK/RESOURCE）分支渲染，避免在各页面重复解析正文。
- 发布/转发共用 `MomentPublishForm`，通过 `isRepost`、`attachResource`、`requireText` 等 props 切换模式，提交前统一调用 `buildMomentContentNodes` 生成正文节点。
- 管理员能力通过 `useRpaAdminStore` 的 `is_root`/`is_admin` 计算属性控制 UI 显隐（如删除入口、审核队列菜单），而非在组件内硬编码权限判断。
