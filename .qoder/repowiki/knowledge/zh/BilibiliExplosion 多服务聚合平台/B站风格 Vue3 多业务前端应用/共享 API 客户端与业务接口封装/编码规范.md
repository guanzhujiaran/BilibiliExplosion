- 业务 API 类以单例形式导出（const xxxApi = new XxxApi(); export default xxxApi），方法直接返回 Promise 而不自行 try/catch。
- 所有对外请求统一经过 businessHandler + adapt 包装，由 adapt 把 hey-api 的 {data,error} 转换为 {code,data,msg} 的 RootObject 契约，再交由 businessHandler 统一提示成功/失败消息。
- 需要区分网络异常与业务失败的接口（如 Nav）使用 responseStyle: 'fields' 获取原始 response 与 error，而非默认的 data 模式。
- 错误处理通过 ErrorHandlerOptions 配置开关（showToast、emitError、customHandler），避免在每个调用点重复编写 toast/emit 逻辑。
- 重定向策略集中通过 useApiRedirect().presets.* 声明式配置（urlPattern、errorCodes、confirmTitle 等），调用方只需传入 response 即可触发对应跳转。
- HTTP 认证采用 HttpOnly Cookie（bili_jwt），请求拦截器仅注入 x-bili-mid/x-bili-level/x-bili-role 与 Accept-Language，不在前端维护 Authorization 头。
